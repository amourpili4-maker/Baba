📘 What is a Decimal?

A decimal number is a number that has a decimal point separating the whole part from the fractional part.

👉 Example: 3.14 → 3 is the whole number, .14 is the fraction (14 hundredths).

➕ Decimal Operations (Quick Tips)

✔️ Addition / Subtraction: Line up decimal points, then add/subtract as usual.

✔️ Multiplication: Multiply normally, then count total decimal places in both factors.

✔️ Division: Move decimal point in divisor to make it whole, shift dividend equally.

Example: 2.5 + 1.75 = 4.25   |   0.3 × 0.2 = 0.06
